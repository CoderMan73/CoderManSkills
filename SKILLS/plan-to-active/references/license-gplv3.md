# GNU General Public License v3.0

> **Research snapshot for plan-to-active**. Verified license text from IQAndreas/markdown-licenses (gnu-gpl-v3.0.md), cross-referenced with the official Free Software Foundation source.

## Key Findings

- The GNU General Public License v3.0 is a free, copyleft license for software and other kinds of works.
- It is intended to guarantee users the freedom to share and change all versions of a program, keeping it free software for all its users.
- It is Version 3, dated 29 June 2007.
- Copyright (C) 2007 Free Software Foundation, Inc.
- Everyone is permitted to copy and distribute verbatim copies of this license document, but changing it is not allowed.
